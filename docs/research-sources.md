# Research sources

Collected 2026-10-03 for the Leaf Doctor pitch (Noor, a smallholder coffee farmer in Kenya).

How sure each source is:

- **Checked**: the page was opened and the figure confirmed directly.
- **Read**: a researcher opened the page and read the figure.
- **Summary only**: the figure came from a search summary and the page was not opened. Open it before quoting.

Do not quote "67,761 substandard bags reached 13,633 Kenyan farmers." No source for it was found.
